# 拍同期の短尺映像レシピ

## 時間設計

`seconds_per_beat = 60 / BPM`、`beat = seconds * BPM / 60`。整数拍で終わるテンポを選ぶと構成しやすいが、指定の尺やテンポを変えてまで合わせる必要はない。例として10秒を120 BPMにすると20拍になり、4拍ごとに2秒の5場面を置ける。

| 拍 | 10秒の例 | 画面 | 音 |
| --- | --- | --- | --- |
| 0–4 | 0–2秒 | タイトルを滑り込ませる | キックと導入音 |
| 4–8 | 2–4秒 | 円・四角・三角・星を補間 | 形の変化に短い効果音 |
| 8–12 | 4–6秒 | ワイヤーのトンネルで奥行き | 低音と細かいハット |
| 12–16 | 6–8秒 | 文字を落として跳ねさせる | スネアと波形 |
| 16–20 | 8–10秒 | 粒子を文字へ集合、最後の決め | 一瞬の無音とアクセント |

これは演出例であり、作品の内容に応じて変える。

## 動きの計算

- 滑り込み: `easeOutExpo(p) = 1 - 2^(-10p)`。開始と終端は明示的に固定する。
- 少し行き過ぎて戻る: back easing。文字や図形の登場に向く。
- 落下と弾み: 正弦波の振幅を時間とともに減衰させるか、bounce easing を使う。
- 図形変形: 各形の輪郭を同じ点数、同じ周回方向で標本化し、対応する点を線形補間する。頂点数だけを急に入れ替えると破綻しやすい。
- 奥行き: `x' = cx + (x-cx) * f/z`、`y' = cy + (y-cy) * f/z`。z を近づけると枠が拡大し、トンネルになる。
- 粒子集合: 文字マスクから目標座標を採り、各粒子の初期座標から easing で移動する。乱数の seed を固定すると再レンダリングで同じ結果になる。

## 実装の選択

- Canvas/HTML: ブラウザ表現や SVG、複雑な文字演出を扱いやすい。フレーム番号を指定して描画できる関数を用意し、ヘッドレスブラウザで各フレームを取得する。
- Python/Pillow/NumPy: 図形、文字、画素ノイズ、簡単な粒子演出を1つのスクリプトで扱える。各フレームを RGB 画像にし、ffmpeg の `rawvideo` 入力へ連続して渡す。
- どちらも必要な場合だけ採用する。どの方式でも、レンダリング時計はフレーム番号から計算する。

映像のフレーム数は原則 `round(duration * fps)`。音声のサンプル数は `round(duration * sample_rate)`。ffmpeg で H.264 / yuv420p と AAC の MP4 にまとめると一般的なプレイヤーで再生しやすい。

## 音声

キック、スネア、ハット、和音、効果音を合成するときは、イベントの時刻を拍番号から求める。キックは下がる低周波の正弦波、スネアやハットは減衰させたノイズ、和音は複数周波数の波で作れる。ピークを検査し、クリッピングを避けて書き出す。無音の演出は最後のアクセント直前など、意図が分かる位置に限定する。ユーザーが指定した音源がある場合は利用条件と指示を優先する。

## 品質確認

- 再生時間、動画・音声の各ストリーム、画面サイズ、fpsをメディア情報で確認する。
- 代表フレームを並べて、文字切れ、場面の抜け、背景とのコントラスト、終端の収まりを見る。
- 場面境界付近を確認し、白フラッシュ、意図しない静止、急な音量差がないかを見る。
- 実際に動画を再生できる環境があれば音と映像の同期を確認する。メタデータ検査だけならその限界を伝える。
